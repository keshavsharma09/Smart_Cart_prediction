# Smart_Cart_prediction
Smart Cart Prediction

Project Overview

Smart Cart is a Python-based Machine Learning project that focuses on customer segmentation using clustering techniques. It analyzes customer spending patterns to identify different customer groups.

Objectives

- Analyze customer data.
- Understand customer spending patterns.
- Identify customer segments.
- Generate useful insights through visualization.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Machine Learning Algorithms

- K-Means Clustering
- Hierarchical Clustering

Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Feature Scaling
6. Customer Clustering
7. Data Visualization

Project Files

- "smart_cart.ipynb" – Project implementation and analysis.
- "smartcart_customers.csv" – Customer dataset.
- "README.md" – Project documentation.
